# Go Generate Integration Example

This example demonstrates how to use `//go:generate` directives for automatic validation code generation.

## 📋 What You'll Learn

- Using `//go:generate` directives for automation
- Struct-level annotations for targeted generation
- Makefile integration
- IDE-friendly development workflow

## 🏗️ Files

- `config.go` - Configuration struct with go:generate directive
- `database.go` - Database configuration with separate generation
- `server.go` - Server configuration
- `main.go` - Example usage
- `Makefile` - Build automation
- `go.mod` - Module definition

## 🚀 Quick Start

1. **Run go generate (recommended approach):**
   ```bash
   go generate ./...
   ```

2. **Or use Makefile:**
   ```bash
   make generate
   ```

3. **Run the example:**
   ```bash
   go run .
   ```

## 📖 Code Walkthrough

### Go Generate Directive

```go
//go:generate go-validate generate --structs AppConfig --verbose

type AppConfig struct {
    Name string `validate:"required,minlen=3"`
    // ... more fields
}
```

### Targeted Generation

Generate validation for specific structs:

```go
//go:generate go-validate generate --structs DatabaseConfig,ServerConfig
```

### Package-level Generation

Generate for all structs in package:

```go
//go:generate go-validate generate
```

## 🔧 Build Integration

### Makefile Integration

```makefile
.PHONY: generate build test clean

generate:
	go generate ./...

build: generate
	go build -o bin/app .

test: generate
	go test ./...

clean:
	rm -f *_generated.go
	rm -rf bin/
```

### IDE Integration

Most Go IDEs automatically run `go generate` when:
- Building the project
- Running tests
- On file save (if configured)

### CI/CD Integration

```yaml
# .github/workflows/test.yml
- name: Generate code
  run: go generate ./...
  
- name: Verify no changes
  run: git diff --exit-code
```

## 🎯 Best Practices

### 1. Specific Struct Targeting

Target specific structs to avoid generating unnecessary code:

```go
//go:generate go-validate generate --structs UserConfig,DatabaseConfig
```

### 2. Verbose Output During Development

Use verbose flag for debugging:

```go
//go:generate go-validate generate --verbose
```

### 3. Dry Run for Verification

Preview generated code:

```go
//go:generate go-validate generate --dry-run
```

### 4. Output Directory Control

Generate to specific directories:

```go
//go:generate go-validate generate --output-dir ./generated
```

## 🔄 Development Workflow

### 1. Add Validation Tags

```go
type NewConfig struct {
    Field string `validate:"required,email"`
}
```

### 2. Add Go Generate Directive

```go
//go:generate go-validate generate --structs NewConfig
```

### 3. Generate Code

```bash
go generate
```

### 4. Use Generated Validation

```go
config := &NewConfig{Field: "test@example.com"}
err := config.Validate()
```

## 🔍 Generated Code Inspection

The generated code is optimized and readable:

```go
// Code generated by go-validate. DO NOT EDIT.

func (a *AppConfig) Validate() error {
    if a.Name == "" {
        return goconfig.NewError().Field("Name").Required()
    }
    if len(a.Name) < 3 {
        return goconfig.NewError().Field("Name").MinLength(3)
    }
    return nil
}
```
